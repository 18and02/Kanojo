# P1 MVP 实施计划

## 目标

实现一个可演示的 Windows 单机桌面智能体:

1. 用户输入文字;
2. 后端检索长期记忆并生成回复;
3. 回复写入对话记录;
4. 对话结束后提取可保存记忆;
5. 低频心跳根据冷却、免打扰与记忆生成主动问候;
6. 桌面端展示聊天、命中记忆、主动触发理由和基础设置;
7. TTS 输出可接入,暂不要求实时流式。

## 非目标

- 不做 STT;
- 不做 barge-in;
- 不做 Live2D;
- 不做双机常驻;
- 不做屏幕活动感知;
- 不做完整心理状态判断。

## 里程碑

| 编号 | 交付 | 验收 |
| --- | --- | --- |
| P1.1 | 后端健康检查 + SQLite 初始化 | `/health` 返回 ok,数据库建表成功 |
| P1.2 | 文字聊天闭环 | `/chat` 能调用 mock 或 OpenAI-compatible LLM,返回回复并保存消息 |
| P1.3 | 记忆写入 / 检索 | 能提取候选、审核落库、记录审计,查询时返回分数和来源 |
| P1.4 | 主动心跳 | 桌面端后台定时检查,冷却和免打扰生效,触发时发桌面通知 |
| P1.5 | 桌面 UI | 能输入消息、显示回复、查看命中记忆 |
| P1.6 | TTS 适配 | 桌面端系统语音可朗读回复,保留外部 TTS 服务配置位 |
| P1.7 | 评测埋点 | 记录延迟、命中记忆、主动触发理由,并在调试页展示摘要 |

## P1 验收指标

- 首 token 延迟:1-3 秒目标;
- 首段语音延迟:3-8 秒目标;
- 每次回复展示命中记忆;
- 主动发言有冷却、免打扰、理由和关闭开关;
- 系统能离线以 mock LLM/TTS 跑通 demo。
- P1.6 语音输出有开关、声音选择、语速、停止和重播。
